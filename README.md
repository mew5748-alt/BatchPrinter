# BatchPrinter v1.4.0 - 批量打印助手

Windows 批量打印工具：把大量、多种格式的文档一次性发送到打印机，无需逐个打开文件。
添加文件 → 选择打印机 → 点击打印，就这么简单。

![Screenshot](https://img.shields.io/badge/platform-Windows%2010%2F11-blue) ![License](https://img.shields.io/badge/license-MIT-green)

## ✨ 核心功能

- **批量打印**：一次添加大量文件，按队列自动依次发送到打印机
- **多格式支持**：PDF、Word、Excel、PPT、RTF、图片（jpg/png/tiff…）、文本（txt/csv…）、PRN/PS/PCL
- **Word / Excel 静默打印**：通过 Office COM 直接把文档转成 PDF 再送打印机，**不弹程序窗口、不弹"正在打印"框**，批次跑完才回来
- **版面可控（只影响打印，不改原文件）**：Word/Excel 可设页边距、纸张方向；Excel 还能「所有列缩到一页宽」「整表缩到一页」「按百分比缩放」、水平居中、打印网格线
- **内嵌打印预览**：界面中间固定一小块预览区，**单击列表里任意文件就立刻显示它的打印效果**（按当前版面/页边距/缩放渲染，与真正打印完全一致），可翻页、缩放，确认无误再打，不浪费纸；不需要时点「👁 打印预览」一键收起，列表立刻变宽
- **压缩包直打**：ZIP / 7Z / RAR / TAR.GZ 内的文件自动解压进队列，无需事先手动解压
- **文件夹递归**：添加整个文件夹（可选含子文件夹），自动筛出可打印文件
- **打印顺序可控**：列表顺序 = 打印顺序。可**拖动行任意调整**先后、上移/下移，也可按「文件名」或「修改时间（早→晚 / 晚→早）」一键重排
- **自然排序**：文件夹与压缩包内的文件按 Windows 资源管理器顺序排列（`1, 2, 10` 而不是 `1, 10, 2`），避免册子打乱页序
- **全局 + 个体设置**：整个列表统一设置份数、色彩模式（黑白/彩色）、单双面、页码范围；**多选后一键批量设置**，或双击单个文件单独设置
- **纸型 / 纸张来源**：右侧「纸型」下拉直接从打印机驱动读取支持的纸型（A4/A3/A5/B5/自定义…），选中即**按纸型缩放**（A4 的文档选 A3 会放大铺满 A3，选 A5 则缩到 A5）；「纸张来源」可选纸盘1 / 纸盘2 / 手送纸盘等，不用再去打印机驱动里改默认值
- **逐页打印**：可让**每一页作为一个独立作业**发送，并设定页与页之间的等待秒数——手动放纸/翻面、逐页核对、卡纸后按页补打都很方便
- **扩展名映射**：非标准扩展名（如 `.dat`）可映射到受支持格式（如 `txt`）间接打印
- **拖拽支持**：直接把文件/文件夹拖进窗口
- **PDF 内置引擎**：无需安装额外软件，PDF 静默直印且完整支持份数/色彩/双面/页码范围
- **免管理员权限**：安装到用户目录，不弹 UAC

## 🚀 快速上手

1. 运行 `BatchPrinter-Setup.exe`（或解压便携版后运行 `BatchPrinter.exe`）
2. 「添加文件 / 添加文件夹 / 添加压缩包」（或直接拖拽进窗口）
3. 工具栏「排序」下拉可切换 添加顺序 / 文件名 / 修改时间；也可直接拖动行改顺序
4. 右侧面板设置全局参数，选择打印机
5. **单击列表里的文件，中间预览区立刻显示它的打印效果**（可翻页/缩放，满意了也能直接点「🖨 打印此文件」只打这一个）
6. 点击「立即打印全部」

### 批量修改多个文件的参数

`Ctrl` / `Shift` 多选列表行 → 点「⚙ 批量设置选中」（或双击任意选中行 / 右键菜单）：

- 份数、色彩、双面、页码范围，**只填你想改的项**，其余保持原样
- 勾选「先清除这些文件已有的单独设置」可把它们全部恢复为跟随全局
- 打印进行中会锁定排序，避免队列与状态错位

### 版面设置（Word / Excel）

右侧「版面设置」区域：

- 勾选 **Excel: 所有列缩到一页宽** —— 最常用，宽表不再横向切页
- 点 **📐 更多版面设置** 可设：页边距（毫米）、纸张方向、整表缩到一页 / 按百分比缩放、水平居中、打印网格线
- 关掉「Office 文件用静默打印」会退回系统关联程序打印（会弹程序窗口，且无法控制版面）——一般不用关

> 所有版面设置**只对打印生效**，原文件不会被改动（程序以只读方式打开，改完即弃）。

### 打印预览

预览区就在列表右侧（默认 330 像素宽），**单击列表里的任意文件它立刻显示打印效果**：

- Word/Excel/PPT 按当前版面（页边距、缩放、方向）生成实际打印效果，显示页数/份数/版面摘要
- 翻页 ◀ ▶、放大缩小、「⤢ 适合宽度」；满意了直接点「🖨 打印此文件」只打这一个
- 用 ↑ ↓ 连续换文件时预览自动跟随，不用鼠标点
- 转换在后台进行，界面不会卡；同一文件同一版面来回点选是秒开（结果缓存）
- 嫌占地方就点工具栏 **「👁 打印预览」** 收起，列表立刻变宽；再点一次展开（状态会记住）
- 支持：Word / Excel / PPT / PDF / 图片；纯文本与 PRN 会提示不支持（这类由打印机驱动排版，预览会失真）

### 纸型 / 纸张来源 / 逐页打印

右侧「打印参数」里多了三项（选项全部来自打印机驱动，不需要手工输入）：

- **纸型**：默认「跟随打印机」。选 A3/A4/A5/B5/信纸/自定义… 后，内容会**按所选纸型缩放**到该纸型的可打印区域——
  A4 的表格选 A3 就放大铺满 A3，选 A5 就整体缩到 A5，不会缺边也不会被裁掉。
  例如 A3 图纸要缩成 A4 存档，或小表要放大贴墙上，直接换纸型即可，不用改原文件。
- **纸张来源**：默认「跟随打印机」。可选驱动报告的进纸盒（纸盘1 / 纸盘2 / 手送纸盘…），
  适合"正文从纸盘1、封面从手送盘"这类场景；打印机不支持该纸型的纸盒时，驱动可能会自动改走手送盘。
- **逐页打印** + 秒/页：勾上后**每一页单独作为一个打印作业**（作业名带「第 N 页」），
  页与页之间按设定秒数等待。适合手动放纸/翻面、逐页核对、卡纸后只补打某一页；
  关掉就是原来的"整份一次发完"。逐页打印走内置 PDF 引擎拆页（比整份发略慢一点）。

> 纸型与纸张来源是通过 DEVMODE 直接交给打印机驱动的（不改打印机默认设置，也不改原文件）。
> 万一同屏放不下这些设置项，右侧设置栏可以上下滚动，「立即打印全部」按钮始终固定在底部。

## 🖨 打印引擎说明

| 格式 | 引擎 | 份数/色彩/双面/页码范围 |
|---|---|---|
| Word / Excel / PPT（docx/xlsx/pptx/wps/et…） | Office COM → 临时 PDF → 内置 PDFium 渲染 + GDI | ✅ 全部精确支持 |
| PDF | 内置 PDFium 渲染 + GDI（装了 SumatraPDF 则优先用它） | ✅ 全部精确支持 |
| 图片 / 文本 | GDI 直印 | ✅ 全部精确支持 |
| prn/ps/pcl | 字节流直送 | 按内容本身 |
| 其他（扩展名映射来的未知格式） | 系统 Shell 打印动词 | ⚠️ 临时写入打印机默认值，尽力生效 |

纸型与纸张来源：前三行走 DEVMODE 直接生效；Shell 通道会临时写入打印机默认值（打完恢复）；RAW 由文件内容自带版面，设置无效。
逐页打印：需要程序内置的 PDF 渲染引擎来拆页，所有格式都走同一套拆页逻辑（RAW 与 Shell 通道除外）。

> Office 文件若检测不到 WPS/Office（COM 不可用），会自动退回系统关联程序打印并在日志里说明；预览窗口对文本/RAW 格式暂不支持（这类文件由打印机驱动直接排版）。

## 🧰 从源码运行

```bash
pip install pywin32 pypdfium2 py7zr rarfile Pillow PySide6
python main.py
```

打包/构建安装器：

```bash
python -m PyInstaller --noconfirm --clean --windowed --onedir --name BatchPrinter --icon=app.ico main.py
python - <<'EOF'
# 生成 setup_payload/payload.zip 后:
python -m PyInstaller --noconfirm --clean --windowed --onefile --name BatchPrinter-Setup --icon=app.ico --add-data "setup_payload/payload.zip;." setup_main.py
EOF
```
